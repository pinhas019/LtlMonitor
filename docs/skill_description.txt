# Skill Monitor Documentation: AutonomousNavigation

## Overview
This skill manages autonomous navigation from a given target location to the goal while ensuring collision avoidance. Its primary goal is to guide the robot successfully to the specified target location. Failure occurs if the navigation process is aborted, canceled, or if a critical safety violation, such as an imminent collision, occurs.

## Monitored LTL Properties
full_navigation_sequence: This liveness property ensures that if a target is received, the system will eventually plan a path, begin moving, and ultimately reach the target. This guarantees that the navigation process does not stall indefinitely after initiation.
collision_imminent: This safety property ensures that the robot must never enter a state where an obstacle is too close. This is critical for physical safety and mandates an immediate halt upon detection.

## Execution Phases

### Phase: PlanningAndInitiation
**Description**
The robot receives the target location and begins the process of calculating a safe path to that location.

**Entry**
Entered from: Idle
When: A target location has been successfully received by the system.
Precondition: True [NONE — checked on entry]

**Safety Invariant**
The robot must never be in a state where a collision risk is present. [SAFETY — immediate halt if violated]

**Progress**
The system must maintain that a path has not yet been planned.
If violated for 5 consecutive steps → skill declared failed.

**Timing**
Minimum steps before exit is allowed: 1 / Maximum steps before TIMEOUT halt: 30

**Exit**
Exits to: ExecutionAndTracking
When: The navigation system has accepted the calculated path plan.

### Phase: ExecutionAndTracking
**Description**
The robot actively moves along the planned path while continuously monitoring its proximity to obstacles and its progress toward the goal.

**Entry**
Entered from: PlanningAndInitiation
When: The navigation system has accepted the path plan.
Precondition: True [NONE — checked on entry]

**Safety Invariant**
The robot must never be in a state where a collision risk is present. [SAFETY — immediate halt if violated]

**Progress**
The robot must remain in a state where it is actively moving towards the target.
If violated for 5 consecutive steps → skill declared failed.

**Timing**
Minimum steps before exit is allowed: 1 / Maximum steps before TIMEOUT halt: 120

**Exit**
Exits to: Done
When: The target has been reached, or the navigation process has explicitly failed.

## Named Failure Modes
collision_imminent: Fault Category: Safety. Monitors: G(!collision_risk). This triggers if the robot enters a state where an obstacle is too close, causing an immediate halt.

## Terminal Conditions

### Success
Condition: navigation_succeeded
This means the navigation status explicitly reports that the robot has successfully achieved the navigation goal.

### Failure
Condition: navigation_failed
This means the navigation process was interrupted, aborted, or canceled by the navigation system.

## Atomic Propositions
target_received | True when distance_to_target > 100.0 | A target location has been set for navigation.
path_planned | True when nav_status == 'accepted' | The navigation system has accepted the path plan.
moving_towards_target | True when nav_status == 'executing' | The robot is actively executing the planned path.
collision_risk | True when min_range < 0.25 | An obstacle is detected too close to the robot.
target_reached | True when distance_to_target < 0.5 | The robot is within close proximity of the target location.
navigation_succeeded | True when nav_status == 'succeeded' | The navigation goal was successfully achieved.
navigation_failed | True when nav_status in ['aborted', 'canceled'] | The navigation process was interrupted or failed.
